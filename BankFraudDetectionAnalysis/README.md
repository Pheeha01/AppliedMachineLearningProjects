# Bank Fraud Detection Analysis
This project focuses on analysing banking transaction data to understand patterns associated with legitimate and fraudulent financial activities. The aim is to explore transaction behaviour, identify unusual patterns and investigate the factors that may be associated with fraudulent transactions.

The analysis will focus on understanding how transaction characteristics, such as transaction amounts, account details, transaction types and locations, relate to fraudulent activity. The insights gained could help demonstrate how data analysis and machine learning can support fraud detection and financial risk management in the banking sector.

## Business Problem

Financial institutions process large volumes of transactions every day, making it difficult to manually identify suspicious activities. Fraudulent transactions can result in financial losses for both banks and their customers.

By analysing historical transaction data, it may be possible to identify patterns that distinguish legitimate transactions from fraudulent ones. Understanding these patterns can support better risk assessment and the development of systems that help detect potentially fraudulent transactions.

## Project Objectives

The main objectives of this project are to:

Explore and understand the structure of the banking transaction dataset.

Investigate the distribution of legitimate and fraudulent transactions.

Analyse transaction amounts, types and locations.

Identify patterns and relationships associated with fraudulent activities.

Examine the characteristics that may help distinguish fraudulent transactions from legitimate ones.

Develop a foundation for future predictive modelling and fraud detection.

## Key Business Questions

The analysis will aim to answer questions such as:

What proportion of transactions are legitimate compared to fraudulent?

Are fraudulent transactions associated with particular transaction types?

Do fraudulent transactions tend to involve higher or lower transaction amounts?

Are there particular locations associated with higher numbers of suspicious transactions?

Which transaction characteristics appear to be most useful in identifying fraudulent activity?

Can patterns in historical transactions help predict whether a new transaction is potentially fraudulent?
